# Ballad of the Green Berets — Barry Sadler (1966)

**Artist:** SSgt Barry Sadler  
**Status for Jake:** **Second song** (after *One Son-Of-A-Gun Of A Gun*)  
**Difficulty:** Beginner-friendly — three open chords

---

## Key / capo
- **Key:** C major (agreed across sources)
- **Capo:** none (Capo +0 / standard open C)
- **Tuning:** standard EADGBE

---

## Chords
**C, G, F** (I–V–IV in C)

Beginner tip for **F:** if full barre `133211` is too hard, use **mini-F** `xx3211` (or `x33211`) until barre strength catches up.

---

## Progression (per verse / chorus)
Same family throughout — four-line pattern. Short lyric hooks only:

```
C          G        C
… soldiers … sky

G               C
… men … die

F            C
… mean … say

G              C
… men … Green Beret
```

Refrain-style lines (“Silver wings…”) use the **same** C–G–C / G–C / F–C / G–C map.  
Outro often ends **F → C** (single strums, let ring).

---

## Strumming
- **March feel:** straight **downstrokes** on the beat (fits the song well).
- **Alternate:** `D-D-U-U-D-U` (cited on Song Tabs).

Start with downs only; add the full pattern once C↔G↔F switches are clean.
